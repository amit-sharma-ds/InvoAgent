Scanner and other devices

Invoices can come into the app without anyone uploading them: from an office scanner that saves its scans in a folder, or from any other system through the API.

1. Scan to folder (office scanner / printer)

Set the scanner to save each scan as a PDF or JPG in a folder on this computer (on most scanners: Scan to folder or Scan to network folder). The app checks the folder every few seconds, reads every new file and moves it into the folder's imported subfolder. The same file is never added twice. Works where the app runs on the office PC.

2. Other systems and devices (API)

Any program or device that can send a file over HTTP (an ERP, a mobile app, a scanning station) can send an invoice and get the extracted data back as JSON. Use the user name and password of an InvoAgent user (HTTP Basic auth).

curl -u USER:PASSWORD -F "file=@invoice.pdf" {{ api_url }}

The invoice is saved like an upload and appears in the Invoices list and the Review queue.
